# 🚀 MERN Stack Case Studies Repository

## 📌 Overview

This repository is a collection of **42 hands-on MERN Stack case studies** completed during my internship at **Indian Institute of Technology (IIT) Ropar** under the guidance of **Prof. Sudarshan Iyengar**.

More than just coding exercises, these case studies helped me understand how software development works in real-world environments. Through practical scenarios, collaborative discussions, daily stand-ups, and continuous learning, I strengthened both my technical and problem-solving skills while building a strong foundation in full-stack development.

The repository covers:

* TypeScript Fundamentals to Advanced Concepts
* React with TypeScript
* MongoDB Database Operations
* Express.js Backend Development
* Software Design Patterns
* Dependency Injection & IoC
* State Management
* Testing & Debugging
* Scalable Application Architecture
